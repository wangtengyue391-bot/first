# 开源把任意文本变成设计师级海报的Skill

![Poster Generator 的 20 种中文海报风格](examples/poster-grid-zh.jpg)

## 做海报，难的不只是生图

做 AI 海报时，真正难的往往不是“生成一张图”，而是前面的这一连串判断：

一大段活动通知里，什么必须保留？什么应该删掉？标题、时间、地点和 CTA 怎么排？该用什么构图、什么风格、什么比例？

如果这些问题没有先解决，再强的生图模型也很容易产出一张“看起来很丰富，但根本不能用”的图。

所以我做了 **Poster Generator**，一个开源的Skill。

它不是一组固定的 Prompt，也不绑定某个生图模型，而是一套从原始内容到最终海报的完整工作流。

你可以直接扔给它一段产品介绍、活动通知、课程文案，甚至一篇没有整理过的长文。它会先理解内容，再完成：

- 提取主标题、关键信息、CTA、视觉主体和信息优先级
- 根据内容密度、发布渠道和画面比例自动组织构图
- 从 20 种视觉风格中推荐合适的方向
- 生成完整、可复用的图像 Prompt
- 调用当前 Agent 环境里可用的生图工具完成渲染

## 一个真实案例：三天音乐节通知

这是我用来测试的一段原始活动通知。它包含三天日程、20 多组艺人，以及时间、地点、入场方式等信息：

```text
一、活动基本信息

举办时间：2026年6月26日-6月28日

举办地点：北京西北旺万象汇·沐风广场

入场方式：免费入场，无需购票

凭入场手环可享场内餐饮折扣

二、每日主题与阵容

6月26日（未来声浪/科技大厂嘉年华）：后浪乐队、涂瑶、老杆子乐队、chopchop、Holly、百度街舞社、诗人说梦乐队、红砖乐队

6月27日（青春声浪/高校毕业歌会）：Deadline乐队、乌曼莉斯乐队、刘彦彤赵梓良、窦翊丹、灰色地带乐队、刘洋可可、ok绷乐队、长命功夫乐队

6月28日（巅峰声浪）：特邀嘉宾海鸣威，以及逆向时钟乐队、王梵瑞&鼓楼先生乐队、女王公园乐队、荒草公园乐队
```

如果把这段文字直接交给生图模型，信息很容易失控。Poster Generator 会先识别“三日日程”这个结构，提炼统一主标题，把艺人阵容压缩到可读密度，再根据内容、渠道和比例决定信息如何组织。

**第一步：分析内容，推荐视觉方向。**

它不会只列出几个风格名称，而是会说明每种风格为什么适合、可能形成什么视觉效果，以及需要注意的风险：

![Poster Generator 分析音乐节内容后给出的视觉风格建议](反馈.png)

**第二步：一次性确认生成选项。**

在确认创作方向、画面比例和生图后端后，Poster Generator 会继续生成图片，无需在多个步骤之间反复问答。这个案例中，我选择了“新粗野主义”。

**第三步：生成最终海报。**

![Poster Generator 生成的新粗野主义音乐节海报](poster.png)

最终画面保留了日期、地点、三天主题、核心阵容和入场信息，同时把复杂内容整理成了清晰的纵向阅读路径。

也就是说，它处理的不只是“画什么”，还包括“该说什么”和“怎么让人读懂”。

## 20 种风格、6 种比例，不限语言

目前内置 20 种视觉风格，包括瑞士编辑、新粗野主义、奢华极简、包豪斯、电影主视觉、编辑拼贴、日式留白、复古未来、超写实产品等；支持中文、英文、日文等多语言，以及 `1:1`、`4:5`、`2:3`、`3:4`、`9:16`、`16:9` 六种比例。

## 不只是给你一张 PNG

我还特意保留了每次生成的完整中间产物：

```text
source.md
  -> analysis.md
  -> structured-content.md
  -> prompts/poster.md
  -> poster.png
```
![Poster Generator 分析音乐节内容后给出的视觉风格建议](海报结果.png)

这意味着结果不是一个不可解释的黑盒。你可以检查它如何理解原文、为什么删掉某些信息、最终 Prompt 是什么，也可以单独修改任意一步再重新生成。

对于需要反复迭代，或者需要把结果交给设计师继续处理的场景，这一点很重要。

## 在 Codex 和 Claude Code 中使用

它遵循 Agent Skills 的目录结构，目前可以在 Codex 和 Claude Code 中使用。

**Codex**

```bash
git clone https://github.com/howardz27/poster-generator-skill.git \
  ~/.agents/skills/poster-generator
```

然后直接调用：

```text
$poster-generator 帮我把下面的活动通知做成一张 4:5 中文海报，风格年轻、有冲击力。
（粘贴原始内容）
```

**Claude Code**

```bash
git clone https://github.com/howardz27/poster-generator-skill.git \
  ~/.claude/skills/poster-generator
```

这个 Skill 与具体渲染工具解耦：只要宿主 Agent 能调用一种图像生成能力，它就会自动发现并接入。你也可以指定自己的 renderer、backend 和质量参数。
